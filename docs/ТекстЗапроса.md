# Форма «Текст запроса»

Открывается из конструктора представлений командой **Показать запрос**. Показывает результат работы конструктора для текущего представления в трёх видах — на отдельных закладках.

## Закладка «Представление»

Текст представления в том виде, в котором его нужно вставить в пакет запросов или в набор данных схемы компоновки:

```bsl
ВЫБРАТЬ
	ДАТАВРЕМЯ(1, 1, 1) КАК Период,
	ЗНАЧЕНИЕ(Справочник.Сотрудники.ПустаяСсылка) КАК Сотрудник
ПОМЕСТИТЬ Представления_КадровыеДанныеСотрудников
ИЗ
	ВТФильтр КАК ВТФильтр
ГДЕ
	"ТолькоРазрешенные" = ЛОЖЬ
```

В текст попадают только поля и параметры, отмеченные в конструкторе; отборы записываются тройками `ЛевоеЗначениеN` / `ВидСравненияN` / `ПравоеЗначениеN`. Текст можно править прямо в форме — например, подставить другие значения параметров. Правки учитываются при формировании исполняемого запроса, но в конструктор не возвращаются.

Кнопки:

- **Скопировать в буфер обмена** — копирует текст закладки.
- **Текст запроса для вставки в код** — переключает вид текста: обычный текст запроса превращается в строковый литерал встроенного языка (текст берётся в кавычки, кавычки внутри удваиваются, каждая следующая строка начинается с `|`), а литерал — обратно в обычный текст. Определяется по наличию символа `|` в тексте.

## Закладка «Исполняемый запрос»

Реальный текст запроса, в который типовой механизм превращает представление: результат вызова `ЗарплатаКадрыОбщиеНаборыДанных.ЗаменитьЗапросыКПредставлениямВиртуальныхТаблиц` для текста с закладки «Представление». Здесь видно, к каким регистрам и справочникам обращается представление, как применяются параметры, отборы и таблица фильтра, — это основной способ изучить и отладить представление.

Запрос формируется при переходе на закладку и пересчитывается только после изменения текста представления. Если текст представления содержит ошибку (неизвестное поле или параметр, неверный синтаксис), вместо запроса выводится сообщение об ошибке с её подробным описанием — исправьте текст на первой закладке и вернитесь на эту.

Кнопки те же: **Скопировать в буфер обмена** и **Текст запроса для вставки в код**.

Исполняемый запрос предназначен для просмотра: в рабочем коде следует использовать текст представления и замену типовым механизмом, чтобы запрос оставался актуальным при обновлении конфигурации.

## Закладка «Код программного интерфейса»

Фрагмент кода на встроенном языке, который создаёт ту же временную таблицу через экспортные функции типовой конфигурации, например:

```bsl
ОписательВременныхТаблиц = КадровыйУчет.ОписательВременныхТаблицДляСоздатьВТКадровыеДанныеСотрудников(
	МенеджерВременныхТаблиц,
	"ВТФильтр");

КадровыйУчет.СоздатьВТКадровыеДанныеСотрудников(ОписательВременныхТаблиц,
												 Ложь,
												 "Период,Сотрудник,ФизическоеЛицо", ,
												 Истина);
```

В код подставлены отмеченные поля, включённые параметры, отборы, таблица фильтра и источник данных. Невключённые необязательные параметры из кода убраны с сохранением позиций аргументов. Код — заготовка: параметры запроса вида `&НачалоПериода` и плейсхолдеры в угловых скобках, которые нельзя вычислить из формы (например, `<ИзмеренияФильтра>`), нужно заменить вручную.

Закладка недоступна, если для представления код программного интерфейса не предусмотрен; в этом случае подсказка закладки сообщает об этом. Кнопка **Скопировать в буфер обмена** копирует код.
