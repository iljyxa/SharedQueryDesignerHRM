# Форма «Конструктор представлений»

Главная форма обработки: выбор представления, отметка полей, заполнение параметров и получение текста запроса. Общее описание механизма представлений и обработки — в основной справке обработки (README проекта).

## Устройство формы

Форма разделена на две части.

**Слева — список представлений.** Каждая строка — представление, доступное в текущей базе: список собран по подсистемам и функциональным опциям конфигурации, поэтому в разных базах он может отличаться. Строки отсортированы по имени. При смене текущей строки правая часть перезаполняется данными выбранного представления.

Командная панель списка: **Добавить** — новое представление, которого нет в описании (например, добавленное расширением конфигурации): имя вводится вручную, поля и параметры добавляются на страницах справа; **Переместить вверх/вниз** — порядок строк списка.

**Справа — страницы выбранного представления:**

- **Поля** — доступные поля представления;
- **Параметры** — источник данных, таблица фильтра, параметры и отборы, уточнение.

Правая часть недоступна, пока в списке не выбрано представление.

## Страница «Поля»

Таблица доступных полей представления.

| Колонка | Назначение |
|---|---|
| **И** | Признак включения поля в запрос. В текст представления попадают только отмеченные поля. |
| Имя | Имя поля представления — под этим именем поле будет доступно во временной таблице `Представления_…`. |
| Выражение | Выражение пустого значения на языке запросов (`ДАТАВРЕМЯ(1, 1, 1)`, `ЗНАЧЕНИЕ(Справочник.Сотрудники.ПустаяСсылка)`, `0`, `""`…). Определяет тип поля до замены представления; формируется автоматически. |

Командная панель таблицы:

- **Установить флажки полей** / **Снять флажки полей** — отмечают или снимают признак включения у всех строк, видимых с учётом текущего отбора.
- **Только используемые** — показывать только отмеченные строки (действует одновременно на таблицы полей и параметров).
- **Добавить** — добавить поле вручную. Нужно для полей, которых нет в описании (например, добавленных расширением): имя и выражение заполняются вручную, новая строка сразу отмечается как используемая.
- **Переместить вверх/вниз** — порядок строк определяет порядок полей в тексте запроса.
- Строка поиска — стандартный поиск платформы по таблице.

Для представлений на основе регистров (`СрезПоследних`, `СрезПервых`, `ТаблицаРегистра`) список полей пуст, пока не выбран регистр в поле «Источник данных» на странице «Параметры»; об этом напоминает подсказка над таблицей.

## Страница «Параметры»

### Источник данных

Виден только для представлений, которым нужен регистр-источник. В списке выбора — периодические регистры сведений конфигурации (регистры с префиксом `Удалить` исключены), каждый показан как «Представление (Имя)». После выбора регистра список доступных полей на странице «Поля» перезаполняется измерениями, ресурсами и реквизитами регистра, а имя регистра добавляется к имени временной таблицы: `Представления_СрезПоследних_ИмяРегистра`.

### Фильтр

Виден только для представлений, поддерживающих таблицу фильтра. Указывается имя существующей временной таблицы того же пакета запросов, поля и значения которой соответствуют доступным полям представления (обычно `Сотрудник`/`ФизическоеЛицо` и `Период` или `НачалоПериода`/`ОкончаниеПериода`); по ней будут отбираться записи результата. Если для представления фильтр обязателен, поле подсвечивается как незаполненное. Для некоторых представлений имя таблицы подставлено по умолчанию — типовой механизм ожидает именно его. Если фильтр допустимо не указывать, без него будут получены все записи.

### Таблица параметров

| Колонка | Назначение |
|---|---|
| **И** | Признак включения параметра в запрос. Обязательные параметры выделены жирным шрифтом и включены по умолчанию. |
| **О** | Признак, что строка — отбор, а не обычный параметр. Отбор записывается в текст тремя параметрами (`ЛевоеЗначениеN`, `ВидСравненияN`, `ПравоеЗначениеN`); признак избавляет от ручного заполнения тройки. Виден только у представлений, поддерживающих отборы. |
| Имя | Имя параметра. Для отбора — имя поля представления: выбирается из списка доступных полей (кнопка выбора или автоподбор при вводе). |
| Вид сравнения | Только для отборов: `=`, `<>`, `>`, `>=`, `<`, `<=`, `В`, `В ИЕРАРХИИ`. Для обычных параметров колонка скрыта. |
| **В** | Признак, что строковое значение — выражение языка запросов. Без признака строка будет заключена в кавычки; с признаком подставлена как есть (`&НачалоПериода`, `НАЧАЛОПЕРИОДА(&ДатаНачала, МЕСЯЦ)`). Механизм представлений не различает типы параметров по тексту, поэтому признак нужен для синтаксически и логически корректного запроса. |
| Значение | Значение параметра. Тип ограничен допустимыми типами параметра; если у параметра есть список допустимых значений (например, периодичность `ГОД`/`КВАРТАЛ`/`МЕСЯЦ`/`ДЕНЬ`), он предлагается для выбора. Очистка значения сбрасывает его в «не задано». |

Командная панель таблицы:

- **Установить флажки** / **Снять флажки** — признак включения у всех видимых строк.
- **Только используемые** — показывать только включённые строки.
- **Добавить** — новая строка параметра или отбора (для представлений с отборами новая строка сразу помечается как отбор). Строка включается в запрос автоматически, значение по умолчанию считается выражением.
- **Переместить вверх/вниз** — порядок строк влияет на порядок условий в тексте запроса.

Изменение значения автоматически включает параметр в запрос.

### Уточнение

Постфикс, который добавляется к имени временной таблицы: `Представления_Имя_ИсточникДанных_Уточнение`. Служит визуальным разделителем и делает имена временных таблиц уникальными, когда в одном запросе нужно несколько одинаковых представлений с разными данными.

## Команды формы

- **Показать запрос** — открывает форму «Текст запроса» с текстом представления, исполняемым запросом и кодом программного интерфейса для текущего представления с учётом отмеченных полей и параметров.
- **Вставить из текста запроса** — запрашивает текст представления (обычный текст запроса или строковый литерал из кода с кавычками и `|`), разбирает его и заполняет форму: соответствующее представление становится текущим, поля и параметры отмечаются и заполняются по тексту, отсутствующие в описании поля и параметры добавляются. Если представления с таким именем в списке нет, добавляется новая строка. При ошибке разбора выводится предупреждение с описанием.
- **Сбросить текущие настройки** — заново заполняет все представления описаниями из кэша: снимает отметки, возвращает значения по умолчанию, удаляет добавленные вручную строки.
- **Вставить** / **Изменить** — доступна, если форма открыта из другой обработки с владельцем. Закрывает форму и возвращает владельцу текст представления. Кнопка называется «Изменить», если форма открыта с параметром `ТекстЗапроса`; в этом случае в заголовок добавляется имя представления.
- **Сбросить кэш описаний представлений** — видна только в режиме отладки. Удаляет кэш и заново собирает описания по конфигурации (например, после включения функциональной опции).
- **Страница проекта** — открывает репозиторий проекта в браузере.

## Параметры формы

Форму можно открывать программно из других инструментов:

- `ТекстЗапроса` — текст представления, который нужно открыть для изменения.
- Наличие владельца формы включает режим вставки/изменения с возвратом текста при закрытии.

Параметры `РежимВставки` и `РежимИзменения` служебные, форма заполняет их сама.

## Кэш описаний

Описания представлений собираются по конфигурации при первом открытии и сохраняются в хранилище настроек пользователя вместе с версиями конфигурации и обработки. При следующих открытиях используются сохранённые описания, пока версии не изменятся. Изменение функциональных опций кэш не отслеживает — в этом случае нужен сброс кэша.
